# 短歌ノートWeb

## 使い方

短歌（主に連作）を作成・推敲するためのサイトです。

## できること

### 基本操作

入力エリアで、タイトル付きの連作短歌を作成することができます。
改行ごとに一首としてカウントされ、空行は無視されます。作成した短歌は連作リストに追加されます。

### 短歌の編集

サイドバーから任意のリストを選択することで以下の操作ができます。

- 短歌の一首ごとの削除・追加
- 短歌の並べ替え（⋮⋮部分をドラッグアンドドロップ）
- 短歌の推敲（変更履歴も確認できます）
- タイトル変更

### 音数カウント

入力した短歌を自動で平仮名に開き、音数（≠文字数）を計算して表示します。
三十一音（定型）の場合文字数部分が緑色にハイライトされます。（定型＝正解とする意図はありません）

### 画像プレビュー

作成した連作を、縦書きの画像形式でプレビューできます。
作成した画像はダウンロード可能。SNS投稿などに使用できます。
背景色・文字色・フォントは変更可能です。
任意でユーザーネームを付記することもできます。

※大体三 ~ 十五首程度を想定しています。また、文字数（≠音数）が三十四文字を超えると改行されます。
