# 短歌ノートWeb

## 使い方

短歌（主に連作）を作成・推敲するためのサイトです。
※PCでの操作を想定しています。スマートフォン・タブレットなどでの使用は非推奨です。

## できること

### 基本操作

入力エリアで、タイトル付きの連作短歌を作成することができます。
改行ごとに一首としてカウントされ、空行は無視されます。作成した短歌は連作リストに追加されます。

### 短歌の編集

サイドバーから任意のリストを選択することで以下の操作ができます。

- 短歌の一首ごとの削除・追加
- 短歌の並べ替え（⋮⋮部分をドラッグアンドドロップ）
- 短歌の推敲（変更履歴も確認できます）
- タイトル変更

### 音数カウント

入力した短歌を自動で平仮名に開き、音数（≠文字数）を計算して表示します。
※自動で漢字を平仮名に変換するライブラリを使っているため、誤変換があります。意図した読みと違う場合は、読み仮名部分を直接編集してください。

### 画像プレビュー

作成した連作を、縦書きの画像形式でプレビューできます。
作成した画像はダウンロード可能。SNS投稿などに使用できます。
背景色・文字色・フォントは変更可能です。
任意でユーザーネームを付記することもできます。

※大体三 ~ 十五首程度を想定しています。また、文字数（≠音数）が三十四文字を超えると改行されます。

### データエクスポート

「エクスポート」ボタンで、作品をバックアップできます。

- エクスポート→ここからダウンロードしたファイルは、「インポート」ボタンから再度インポートできます。ブラウザの履歴やキャッシュを消去する（且つ、その後再度このサイトを使いたい）際のバックアップ用です。
- 本文のみエクスポート→短歌本文だけのプレーンなテキストです。本文だけのデータで十分な場合はこちらがおすすめです。

### データインポート

ダウンロードしたテキストファイルは、再度インポートできます。

1. 「ファイルを選択」ボタンをクリック
2. PC内からファイルを選択（変更していない場合、デフォルトファイル名は「YYYYMMDD_HHmmss_tankanoteweb.json」です）
3. 「インポート」ボタンをクリック
4. 「データを上書きしますか？」とポップアップが表示されるので、許可するなら「OK」をクリック
5. 「データのインポートが完了しました！」に「OK」をクリック

※もし反映されない場合は、サイトのリフレッシュを試行してください。

### テーマ切り替え

画面左上のトグルボタンから、ライトモード/ダークモードを切り替えられます。

### データのセキュリティについて

入力内容はご利用のブラウザ（ローカルストレージ）にのみ保存され、外部へ送信されることはありません。 ただし、機密情報は入力しないでください。

※ブラウザのデータ削除により内容が全消去されます。必要に応じてデータをバックアップ（エクスポート）してください。
